### 📌 数据源决策（v4 调整）

> **背景**：Phase 0 黄金样本生成阶段历经多轮数据源验证：
> - mootdx 0.11.7 对历史日期范围查询存在固有 bug（`get_k_data` 偏移计算错误 → 空 DataFrame → `KeyError: 'datetime'`），且行情服务器权限/连通性不稳定，无法稳定取数；
> - baostock 在当前环境**无法获取 ETF 行情**（实测 `sh.510300`/`sh.510180`/`sz.159915` 等均返回空），仅 A 股+指数可用；
> - Tushare 经私有代理 `ts-2.cwy666.com`（已开通 `daily`/`index_daily`/`fund_daily`）可稳定覆盖 A 股 / ETF / 指数三类标的。
>
> **用户最终决策（v4）**：
> 1. **全局统一使用 Tushare 取数**，mootdx 与 baostock **均已弃用**，本次改造不再使用任何 baostock/mootdx 数据路径。
> 2. Phase 0 黄金样本 3 组全部经 Tushare 生成（A 股 600000.SH / ETF 510300.SH / A 股 600519.SH 跨多年）。
> 3. Phase 3-3（mootdx fetcher 迁移）、Phase 3-4（数据层一致性验证）、Phase 6-2（mootdx CLI 改造）、Phase 6-3（CLI 一致性验证）中涉及"mootdx 路径"的步骤，因 mootdx 已弃用，**改为以 Tushare 为唯一数据路径**进行迁移与对比验证；原"mootdx 延后验证"策略作废。
> 4. Tushare 接入方式见 `tushare_client.py`（私有代理地址 + token，token 优先读环境变量 `TUSHARE_TOKEN`）。
>
> 该决策已同步更新 Step 0-4 规格与《环境基线》。
