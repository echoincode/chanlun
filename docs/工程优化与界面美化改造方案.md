  - 视觉/默认参数：`DEFAULT_CODE="600000"`、默认起止日期、`DATA_SOURCES=["mootdx","baostock"]`、`FREQ_OPTIONS=["5","15","30","60"]`、默认 `index=2`、`CHART_HEIGHT=800`。

  - 算法层阈值（`window=4`、`min_gap=4`、`merge_klines` 规则等）**位于 `chanlun_processor.py` 内部，保持原位不抽离**，本配置文件不触碰。
- **数值一律不变**，只做"位置迁移"。

### 3.4 `src/utils/logger.py` 🔧（新建·替换范围受限）

### 3.5 `src/utils/common.py` 🔧（去重封装·统一 5 处重复，基准取最完整实现）
- **重复源核查（5 处，非 3 处）**：
  1. `app/main.py`（第 32–112 行）✅ 有 `get_market_type`，`normalize_stock_code` 完整（含 ETF/港股/北交所分支）
  2. `app/utils.py`（第 11–122 行）✅ 同上，作为**统一基准**
  3. `mootdx_chanlun.py`（第 34–94、184–235 行）✅ 同上（无港股格式分支例外提示）
  4. `baostock_chanlun.py`（第 33–148 行）❌ **无 `get_market_type`**，`normalize_stock_code` **缺 `5`→sh ETF、`15`→sz ETF 两分支**（baostock 历史不支持 ETF）
  5. `mootdx_data_fetcher.py`（第 329–372 行）❌ 仅有 `_get_market_from_code` 返回数字，**无港股分支**
- **抽取规则（避免改变既有行为）**：
  - 统一基准取 **`app/utils.py`** 实现，迁到 `src/utils/common.py`，供 web/cli 共用。
  - `baostock_chanlun.py` 改薄封装时**主动跳过 ETF/港股分支判断**（或运行时提示"baostock 不支持 ETF"），不悄悄补齐其 ETF 能力。

  - `app/utils.py` 的 `display_error/success/info/warning/metric` **本项目从未被 main.py 引用**，迁移到 `common.py` 时**直接删除**（不增加调用点改造工作量）。
- 逻辑等价迁移，不改变算法结果。

### 3.6 `src/data/base_fetcher.py` + 两个 fetcher 📦🔧（接口契约明确）
- **抽象基类契约草案**：
  ```python
  # src/data/base_fetcher.py
  class BaseFetcher(ABC):
      def fetch_daily(code, start, end, adjustflag='2') -> pd.DataFrame: ...
      def fetch_minute(code, start, end, frequency, adjustflag='2') -> pd.DataFrame: ...
      def fetch_etf(...) / fetch_index(...) / fetch_hk(...)  # 子类按需 override，默认 NotImplementedError
  ```
- 设计原则：**取数接口统一 + 多市场扩展由子类各实现一份**，禁止 base_fetcher 内部长出 `if-elif` 市场类型链。
- `AStockDataFetcher`（baostock）：一次性 `bs.query_history_k_data_plus` + 字段重命名清洗（保持原样）。
- `MootdxDataFetcher`（mootdx）：线路选优 + 按市场分派 + 分批次 `bars()` + 港股独立服务器（保持原样）；其中 `best_server.json`（运行时生成）**读写逻辑不变**，加入 `.gitignore`。
- **不改取数 API 调用与返回结构**，确保数据一致。

### 3.7 `src/cli/runner.py` 🔧（新建·计算核心下沉，保留行为差异）
- 抽出"取数 → `ChanlunProcessor.process_klines` → 可视化"的**计算核心**，入参与执行顺序与原代码一致。
- **维度澄清**：原 web 侧 `analyze_stock_with_mootdx/baostock` 含 `@st.cache_data` 缓存 + 数据源×市场类型(A股/ETF/指数/港股)×数据格式三维分支；CLI 侧无缓存、单一数据源。

  - 交互式 CLI 的 `input()` 循环、图表保存/展示逻辑**保留在 `scripts/*.py` 侧**，runner 不接管交互。

## 5. 验证方法（优化前后结果一致性）

> 目的：用 `project_backup` 作为基准，证明改造后分型/笔输出 100% 不变。**优先以离线黄金样本为准，实盘对比作补充**。

### 5.1 离线黄金样本（推荐·确定性高）
- **目录**：`tests/golden_samples/`
- **原始数据**：CSV，列 `datetime,open,high,low,close,volume,amount,code`，文件名 `<source>_<code>_<freq>_<start>_<end>.csv`
- **期望结果**：JSON，含 `fractals`（每项 `index/type/high/low/datetime`）+ `segments`（每项 `start_idx/end_idx/start_type/end_type/direction/start_price/end_price`），文件名 `<source>_<code>_<freq>_<start>_<end>.expected.json`
- **样本规模**（至少 3 组）：
  1. A 股日线：`mootdx_sh.600000_daily_2024-01-01_2024-12-31`
